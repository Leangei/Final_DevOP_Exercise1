📇 ID Card Management System

Spring Boot application for managing student and employee ID cards

Application Running
📋 Profiles API 🎨 Templates API 💚 Health Check

📋 Core Features

👤 Profile CRUD

Create, read, update, delete student, employee, and user profiles with full validation.

5 ptsGET /api/profiles

📸 Photo Upload

Upload JPEG/PNG photos (max 5MB) for ID cards. Validates file size and type.

3 ptsPOST /api/profiles (multipart)

🎨 Template Engine

Thymeleaf HTML/CSS templates for ID card layout with customizable colors and organization name.

2 ptsGET /api/templates

👁️ Live Preview

Instant preview of the ID card after entering details. Enter a profile ID to preview.

5 ptsGET /preview/{id}

🔢 ID Generation

Auto-generated UUIDs and custom registration numbers in YEAR-DEPT-### format.

2 ptsAuto on profile create

📄 PDF Export

Generate ID cards as downloadable PDF files using iText library with full card layout.

5 ptsGET /api/pdf/{id}

📦 Batch Generation

Create multiple ID cards at once for teams, classes, or employee groups as ZIP archive.

2 ptsPOST /api/pdf/batch

📱 QR Code

Generate QR codes with profile verification URLs using ZXing library. Embedded on cards.

3 ptsGET /api/qrcode/{text}

🔲 Barcode Support

Code-128 and EAN-13 barcodes generated from registration numbers. Embedded on cards.

3 ptsGET /api/barcode/{id}
