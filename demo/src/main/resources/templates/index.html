📇 ID Card Management System

Spring Boot application for managing student and employee ID cards

Application Running
👤 Manage Profiles 🎨 Manage Templates 📦 Batch Generation 💚 Health Check

📋 Features

👤 Profile CRUD

Create, read, update, delete student, employee, and user profiles with photo upload.

5 pts

📸 Photo Upload

Upload JPEG/PNG photos (max 5MB) for ID cards with file type validation.

3 pts

🎨 Template Engine

Thymeleaf HTML/CSS card templates with customizable colors and branding.

2 pts

👁️ Live Preview

Instant preview of ID cards with QR code and barcode. Click "Preview" on any profile.

5 pts

🔢 ID Generation

Auto-generated UUIDs and registration numbers in YEAR-DEPT-### format.

2 pts

📄 PDF Export

Download ID cards as PDF files via the "PDF" button on each profile.

5 pts

📦 Batch Generation

Select multiple profiles and generate all ID cards at once as a ZIP archive.

2 pts

📱 QR Code

QR codes with profile verification URLs generated via ZXing on each card.

3 pts

🔲 Barcode Support

Code-128 and EAN-13 barcodes generated from registration numbers on cards.

3 pts

Built with Spring Boot 3.2.5 + MySQL | Total: 30 points
